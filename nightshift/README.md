# NIGHTSHIFT: STREET LEGENDS

Браузерная 3D-игра о ночных гонках. Город, машины, физика, режимы, интерфейс и звук находятся в этом проекте; сервер игрового процесса не нужен. Управление рассчитано на клавиатуру.

## Запуск на Windows 10

1. Установите актуальный Node.js 22 LTS и откройте PowerShell в папке проекта.
2. Для быстрого запуска готовой сборки выполните:

```powershell
npm start
```

Для разработки и пересборки вместо этого выполните `npm install`, затем `npm run dev`.

3. Откройте в Chrome адрес, который появится в терминале: обычно `http://localhost:4173/` для `npm start` или `http://localhost:5173/` для Vite. Выберите режим и нажмите **«На старт»**.

Для сборки: `npm run build`. Для проверки физики: `npm test`. Сохранения хранятся в `localStorage` браузера: используйте тот же браузер и адрес. Очистка данных сайта удалит прогресс.

## Управление

| Клавиши | Действие |
| --- | --- |
| W / S | Газ / тормоз и задний ход |
| A / D | Поворот |
| Space | Ручной тормоз и занос |
| Shift | Нитро |
| C | Камера: сзади, капот, дальняя |
| R | Восстановление машины |
| Esc | Пауза; в свободной поездке через паузу можно завершить заезд |

## Режимы

- **Street Race:** два круга и три соперника; нужно финишировать первым.
- **Drift King:** наберите 2 000 очков за 90 секунд.
- **Highway Rush:** пройдите 1 200 метров среди трафика за 100 секунд.
- **Drag Battle:** отдельная прямая на 400 метров, победа — пересечь финиш раньше соперника.
- **Time Attack:** восемь контрольных точек за 75 секунд.
- **Free Ride:** исследуйте город. Проедьте не менее 250 метров и завершите поездку через паузу; пять серьёзных столкновений приводят к поражению.
- **Police Escape:** продержитесь 60 секунд, не позволяя полиции оставаться рядом пять секунд.
- **Parking Challenge:** остановитесь в отмеченном месте на две секунды за 90 секунд.
- **Elimination:** каждые 25 секунд выбывает последний; победа — остаться одному.

В гараже доступны шесть процедурных автомобилей, покупка за кредиты, выбор, цвет, диски, подвеска и три уровня улучшений двигателя, тормозов и сцепления. Награда за заезд добавляется к сохранённым кредитам.

## Графика и производительность

В настройках выберите Low, Medium или High; изменение качества применяется после перезагрузки страницы. Там же можно отключить частицы и изменить громкость. Дальность видимости ограничена туманом, пиксельное разрешение ограничено, здания, окна, фонари и дорожная разметка используют instancing, материалы и геометрия переиспользуются. Дым и следы шин ограничены по числу объектов. Теневые карты и трассировка лучей не используются. В HUD есть FPS-счётчик.

**30 FPS на i3-4130T / GeForce 800M не подтверждены:** этот компьютер не был доступен для проверки. В отдельной пробе программного WebGL на нашей среде частота была около 8 FPS, поэтому она не является оценкой работы на вашей видеокарте. Для игры нужен Chrome с работающим WebGL 2; начните с Low и оцените FPS в самом заезде.

## Текущие ограничения

Машины и город состоят из простых процедурных геометрических форм. Полиция и трафик используют упрощённые маршруты; AI не строит путь с обходом препятствий, а столкновения с постройками применяются к машине игрока. Мост обозначен дорожными перилами, отдельной многоуровневой трассы нет. Фары — светящиеся элементы моделей, без динамических световых конусов. Музыкального сопровождения нет: Web Audio синтезирует двигатель и удар. Управления с сенсорного экрана нет.

## Повторить браузерные проверки

Дополнительно установите Python Playwright и Chromium, запустите `npm run dev` в отдельном окне, затем:

```bash
python tests/browser-smoke.py
python tests/real-modes.py
```

Можно задать переменные `NIGHTSHIFT_URL` и `CHROME_BIN`. Браузерные тесты создают отдельный временный профиль и не используют ваш игровой прогресс.

## Структура

`src/core` — ввод; `src/game` — игровой цикл и ограниченные эффекты; `src/physics` — физика машины; `src/world` — город; `src/vehicles` — модели; `src/modes` — условия режимов; `src/data` — каталог и сохранения; `src/ui` — интерфейс; `src/audio` — звук; `src/styles` — оформление. Тесты — в `tests`.

## Дизайн-бриф

Игрок открывает игру за компьютером и хочет быстро выбрать заезд; главное действие — выйти на старт. Ночные уличные гонки, городской маршрут и преследование — игровые ориентиры жанра, знакомые по Need for Speed: Underground 2, Midnight Club 3 и Need for Speed: Most Wanted соответственно. Идея интерфейса — меню как приборная панель ночного заезда с выбранным режимом и его условиями. Название, девять режимов, цвета и требования к оборудованию взяты из задания; машины и их игровые цены созданы для проекта. Шрифты DejaVu поставляются локально, лицензия — `src/assets/FONT-LICENSE.txt`.
