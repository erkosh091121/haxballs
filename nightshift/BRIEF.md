# PROJECT: NIGHTSHIFT — STREET LEGENDS

Ты — команда профессиональных разработчиков браузерных 3D-игр: Senior Three.js Engineer, Gameplay Programmer, Technical Artist, UI/UX Designer и QA Engineer.

## ГЛАВНАЯ ЗАДАЧА

Создай полноценную браузерную 3D-гоночную игру NIGHTSHIFT: STREET LEGENDS.

Это должен быть настоящий запускаемый проект с игровым процессом, а не демонстрационный макет, статичная сцена или красивое меню без функциональности.

**Технологии:**
- HTML5, CSS3, JavaScript ES Modules
- Three.js для 3D-рендеринга
- Vite для разработки и сборки
- Лёгкая физика автомобиля на JavaScript
- Web Audio API для звуков
- localStorage для сохранений

**Целевое оборудование:**
- Intel Core i3-4130T, 2.9 GHz
- 8 GB DDR3 RAM
- NVIDIA GeForce 800M, 1 GB VRAM
- Windows 10
- Chrome, WebGL

Цель — стабильные 30 FPS при 1280×720 на минимальных настройках, если это подтвердят реальные тесты.

## 1. GAMEPLAY

Реализуй управление автомобилем:

W — газ  
S — тормоз и задний ход  
A/D — поворот  
Space — ручной тормоз  
Shift — нитро  
C — переключение камеры  
R — восстановление автомобиля  
Esc — пауза

Физика должна включать:
- Разгон и замедление
- Сцепление с дорогой
- Управляемый занос
- Инерцию
- Тормозной путь
- Столкновения
- Разницу между автомобилями
- Работающий нитро-ускоритель

Не используй тяжёлые физические движки без необходимости.

## 2. ДЕВЯТЬ РЕЖИМОВ

1. Street Race — гонки с ИИ-соперниками.
2. Drift King — дрифт с подсчётом очков.
3. Highway Rush — движение среди трафика.
4. Drag Battle — гонка на короткой дистанции.
5. Time Attack — гонка на время.
6. Free Ride — свободная езда.
7. Police Escape — преследование полицией.
8. Parking Challenge — парковка.
9. Elimination — гонка на выбывание.

Каждый режим должен иметь реальные условия старта, победы, поражения, начисления наград и экран результатов.

## 3. МИР

Создай компактный оптимизированный город с:
- Дорогами и перекрёстками
- Тоннелями
- Мостами
- Небоскрёбами
- Промышленной зоной
- Автомагистралью
- Парковками
- Уличными фонарями
- Декоративными неоновыми вывесками

Используй модульную геометрию, повторное использование материалов и instanced meshes.

Не создавай огромный бесконечный мир. Важнее качество и производительность.

## 4. АВТОМОБИЛИ

Создай минимум 6 оригинальных автомобилей разных классов.

Каждый автомобиль должен иметь:
- Отдельную 3D-модель
- Вращающиеся колёса
- Фары и задние фонари
- Характеристики
- Стоимость
- Настройки внешнего вида
- Различия в управлении

Не используй защищённые автомобильные логотипы без разрешения.

## 5. ГАРАЖ

Реализуй:
- Покупку автомобилей
- Выбор активного автомобиля
- Улучшение двигателя
- Улучшение тормозов
- Улучшение сцепления
- Изменение цвета

- Настройку подвески
- Предпросмотр автомобиля в 3D

Все покупки и улучшения должны сохраняться.

## 7. ГРАФИКА

Реализуй:
- Стилизованную ночную атмосферу
- Туман для ограничения дальности прорисовки
- Фары
- Неоновую подсветку

- Эффект скорости

## 8. ОПТИМИЗАЦИЯ

Обязательно:
- Ограничение devicePixelRatio
- Frustum culling
- InstancedMesh
- Повторное использование геометрии
- Ограничение количества draw calls
- Лёгкие материалы
- Минимум динамических теней
- Настройки Low / Medium / High
- Опциональное отключение частиц
- Ограничение дальности прорисовки
- Отсутствие утечек памяти

Предусмотри FPS-счётчик.

## 10. ПОРЯДОК РАЗРАБОТКИ

Работай по этапам:

Этап 1 — Vite, Three.js, игровая сцена, камера и управление.

Этап 2 — физика автомобиля, столкновения, трасса, HUD.

Этап 3 — первый полностью работающий режим Street Race.

Этап 4 — остальные режимы, реализованные по одному.

Этап 5 — гараж, экономика, автомобили, сохранения.

Этап 6 — графика, анимации, звук и оптимизация.

Этап 7 — тестирование, исправление ошибок, сборка.

После каждого этапа проверяй работоспособность. Не переходи к следующему этапу, если базовые функции сломаны.

- npm install выполняется без критических ошибок.
- npm run dev запускает игру.
- npm run build успешно собирает проект.
- Автомобиль реально управляется.
- Есть столкновения.
- Камеры переключаются.
- Игровые режимы запускаются и завершаются.
- ИИ-соперники движутся по трассе.
- Гараж и покупки работают.
- Прогресс сохраняется после перезагрузки.
- Нет критических ошибок в консоли.

Не объявляй функции реализованными, если они не работают.

Если для полного объёма требуется несколько итераций, сначала создай качественное играбельное ядро, затем последовательно расширяй игру.
