# NIGHTSHIFT — состояние проекта

Реализованы Vite/Three.js-сцена, компактный город, управление, физика, столкновения игрока, девять режимов, шесть процедурных машин, гараж, экономика, настройки, локальные сохранения, три камеры, HUD, пауза и результаты. Звук двигателя и ударов синтезируется Web Audio; следы и дым ограничены по числу объектов. Источники разделены по директориям src.

Проверены npm ci, npm test, npm run build, Chromium с программным WebGL, реальные вводы W/C/Esc, покупка и сохранение. Все девять режимов завершены в автоматической симуляции управления; Free Ride — после минимальной дистанции через паузу. Победные и проигрышные ветки проверены дополнительно, в том числе установкой игровых состояний. Подробности и ограничения — README.md. Целевое оборудование не тестировалось; 30 FPS не подтверждены.

Запуск: npm install, npm run dev. Полная сборка: npm run build.

Финальная оптимизация: разметка и фонари переведены в instanced meshes; в одном контрольном кадре число draw calls снизилось со 107 до 68. Программный WebGL показал около 8 FPS на данной среде; результат на целевом GPU неизвестен. Добавлен локальный запуск готовой dist через npm start без установки npm-пакетов.
