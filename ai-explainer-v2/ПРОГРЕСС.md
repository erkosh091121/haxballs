# Переработка визуального ряда
Исходный ролик сохранён в /workspace/ai-explainer. Новая версия изолирована в /workspace/ai-explainer-v2.
Задача: процедурные объёмные кадры по референсам нейронов, многослойного чипа и потока частиц. Сначала три контрольных кадра и короткая анимационная проба, затем полный MP4 60 с 1080×1920 60 fps.
Раскадровка: storyboard.md. Используется существующая русская речь и оригинальная музыка исходного проекта.
Текущий этап: реализация самостоятельного программного рендера.

Созданы и просмотрены семь контрольных кадров. Исправлены масштаб чипа, материал центрального узла, ширина потока частиц, контраст вложенных областей, безопасные зоны текста. Создана проба style-preview-v2.mp4: 9 с, 540×960, 24fps с музыкой, три отдельных мотива. Полный native 1080×1920/60fps рендер запущен renderer.py --full --workers 3; лог renders/full-render.log. Старая версия не перезаписана.

Созданы три квадратных native кадра по референсам: reference-neurons.png, reference-processor.png, reference-particles.png (1080×1080). Они, как и анимация, полностью процедурные. Рендер полного видео прошёл 1592/3600 кадров; журнал full-render.log. Все ресурсы новой версии локальны, шрифты скопированы в assets/fonts. Для продолжения: дождаться renderer.py, затем python verify.py. Ограничения проверки записаны в REVIEW.md.

ГОТОВО: renders/inside-ai-v2.mp4, native 1080×1920, 60 fps, 3600 кадров, 60.000000 с, H.264 4:2:0 full range и AAC. Финальный CRF 19; первичная сборка CRF 17 сохранена отдельно как master, в архив и GitHub не включается. Проверены технические параметры, полное декодирование и выборки кадров границ сцен. motion-check.json: 3600 кадров, 0 ошибок, максимальная почти статичная серия 1/60 с. Непрерывный просмотр/прослушивание человеком не выполнены — ограничения в REVIEW.md. Далее создаётся архив исходников и добавляется папка ai-explainer-v2 в GitHub haxballs.
