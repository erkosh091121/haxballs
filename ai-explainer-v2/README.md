# Внутри ИИ — процедурная визуальная версия 2

Полный ролик: `renders/inside-ai-v2.mp4`.
Проба трёх мотивов: `renders/style-preview-v2.mp4`.
Контрольные кадры: `renders/style-1.png`…`style-7.png`.

Все сцены созданы кодом. Референсы пользователя используются только как художественный ориентир; их изображения не включены в кадры как фоны или текстуры. Нейрон — художественная метафора вычислительного узла.

## Технология
Python, NumPy, Pillow, FFmpeg. Собственная перспективная камера; объёмные положения и поверхности; многослойный процессор; траектории сигналов; волокнистые нейроны; 7800 частиц; размытие дальнего плана и отдельный проход светового рассеяния. Материалы — процедурное художественное приближение, не физический ray tracing. Направления, геометрия и движения определяются временем, случайность фиксирована seed.

Прежняя русская озвучка Piper и оригинальный музыкальный микс сохранены. Для этой версии внешние сервисы генерации не используются.

## Повторный запуск
Python 3.12+, FFmpeg/FFprobe.

```bash
python -m pip install -r requirements.txt
python renderer.py --stills
python renderer.py --preview --start 42 --end 48 --workers 2
python renderer.py --full --workers 3
python verify.py
```

Итог: 60 секунд, 1080×1920, 60 fps, ровно 3600 кадров, H.264, 8-bit 4:2:0 (full range), AAC stereo. На слабом компьютере используйте `--workers 1`; выходные параметры сохранятся. `--preview` меняет только характеристики отдельной пробы на 540×960/24fps.

Финальный рендер проходит по кадрам в `renders/frames-inside-ai-v2/`, затем собирается FFmpeg. Папка кадров — промежуточный кэш, для воспроизведения видео не нужна.

Для разработки сцены редактируются в `renderer.py`: `neurons`, `nesting`, `particles`, `chip`, `overlay`. Речь с таймкодами — `assets/narration.json`; единый микс — `assets/master.wav`. Для регенерации речи используйте сохранённый проект первой версии, здесь все необходимые звуковые дорожки уже локальны.

Проверки и их ограничения записаны в `REVIEW.md`. Эта версия не заявляется точной копией референсов или физически достоверной визуализацией биологических нейронов.
