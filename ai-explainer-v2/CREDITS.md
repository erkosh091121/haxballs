# Материалы

Геометрия, узлы, волокна, процессор, трассы, частицы и анимация созданы оригинальным процедурным кодом renderer.py для этого проекта.

Изображения-референсы пользователя не встроены в результат и не включены в архив. Они служат художественным ориентиром.

Шрифты: DejaVu Sans, лицензия в licenses/DejaVu.txt.

Русская речь: локальный Piper, модель ru_RU-denis-medium; карточка исходной модели: https://huggingface.co/rhasspy/piper-voices/tree/main/ru/ru_RU/denis/medium — датасет CC0. Здесь используется готовый локальный микс из первой версии проекта.

Музыка и эффекты: оригинальный процедурный синтез исходного проекта, без сторонних музыкальных записей. Полный микс: assets/master.wav. Для данной версии он не отправлялся во внешние сервисы.
