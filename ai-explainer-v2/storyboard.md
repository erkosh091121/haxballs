# Визуальная переработка по трём референсам
Тайминг и русская озвучка исходного 60-секундного ролика сохранены. Сцены генерируются кодом, изображения пользователя не используются как текстуры.

| Время | Три варианта | Выбранное решение и движение |
|---|---|---|
| 0–5 | Органические узлы / кремниевый тоннель / абстрактный мозг | Объёмные бирюзовые узлы с волокнами и окончаниями связей. Небольшой боковой пролёт к главному узлу, импульсы по связям. Художественная метафора, не биологическое устройство ИИ. |
| 5–13 | Вложенные сферы / вложенные объёмы / раскрывающиеся оболочки | Три вложенных пространственных области, последовательное выделение ИИ → МО → ГО. Камера движется по дуге; подписи остаются читаемыми. |
| 13–21 | Частицы из документов / воронка данных / каналы модальностей | Потоки частиц формируют обучаемую модель. Передний, средний и задний планы; частицы различаются по размеру и резкости. Метки типов данных сменяются подготовкой и числовыми представлениями. |
| 21–32 | Слоистая органическая сеть / матрица весов / отдельный нейрон | Световые сигналы идут через три пространственных слоя узлов. Обратное изменение связей и убывающий график ошибки. Плавное сопровождение сигнала. |
| 32–42 | Чип Transformer / токеновый тоннель / матрица внимания | Токены, связи внимания и многослойный вычислительный блок. Печатный вывод ответа, без растягивания букв. |
| 42–52 | Разобранный чип / серверный кластер / кремниевая макросъёмка | Изометрический многослойный процессор с металлическими поверхностями, крышкой над кристаллом, трассами и движущимися сигналами. Короткий неполный облёт. |
| 52–60 | Сборка частиц / схема двух этапов / вычислительное ядро | Частицы сходятся к модели; отдельные пути обучения и нового запроса. Финальные слова крупные. Свет и музыка плавно затухают к 60 с. |

Палитра: почти чёрный сине-графитовый фон, холодные белые и бирюзовые источники, ограниченные тёплые и фиолетовые акценты из референсов. Неон используется локально, не сплошной заливкой. Глубина резкости — по расстоянию объектов, световое рассеяние — отдельным проходом. Геометрия и камера определяются временем и фиксированным seed.
