## Исходники

Полный архив проекта разделён на части `inside-ai-project.zip.part*`, чтобы уложиться в ограничения загрузки GitHub. Скачайте все части, `archive-manifest.json` и `restore_project.py` в одну папку, затем выполните:

```bash
python restore_project.py
```

Будет создан `inside-ai-project.zip`; скрипт проверяет SHA-256 частей и итогового архива. Внутри — исходники сцен, голосовая модель, речь, музыка, эффекты, локальные ресурсы, зависимости и инструкция экспорта. Можно также клонировать репозиторий и запустить `python ai-explainer/restore_project.py`.

Параметры видео и полное декодирование проверены. Полноценное прослушивание и непрерывная визуальная приёмка не выполнены. Все ограничения указаны в `REVIEW.md` внутри архива.

Анимация: Three.js / GSAP / Hyperframes. Локальная речь: Piper.
